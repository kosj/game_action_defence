# 생존자 작전 장비 UI

2026-09-13. 메인 로비·전투 HUD·레벨업/진화 선택에 적용한 최종 디자인.

## 시각 규칙

- 무광 건메탈 `#202629`, 얇은 강철 테두리 `#4A565B`, 아이보리 글자 `#EEE7D8`.
- 주요 시작 버튼·체력은 적색 `#B83A35`, 경험치·강화는 청록색 `#72B9AD`, 보상·진화는 황동색 `#C5A060`.
- Godot의 StyleBoxFlat/Container를 사용한다. 기존 배경·캐릭터·아이콘과 저장/게임 데이터는 그대로 사용한다.
- `UIStyle.tactical_*`와 `UITheme.TACTICAL_*`를 명시적으로 적용한다. 기존 옵션·강화·캐릭터 선택 등 팝업은 전역 스타일 교체 대상이 아니다.

## 화면 구성

- 로비: 로고/설정, 계정 재화, 기존 캐릭터 초상과 설명, 아레나, 시작 버튼, 강화/과제/보상/기록. 이어하기가 있으면 우선 표시한다. 기록에는 도전과제·도감과 기존 모드별 최고점을 모았다.
- HUD: 상단 184px(720×1280에서 14.4%)에 체력·시간·재화·처치·레벨·경험치·타임라인. 경고와 보스 체력은 별도 영역을 쓴다. 하단에 무기/패시브를 분리하고 캐릭터 궁극기를 포함한 일곱 번째 무기도 표시한다.
- 일반 토스트는 한 줄씩 순서대로 표시한다. 보스 길 안내, 달성 알림, 자석 효과 알림도 새 HUD와 겹치지 않도록 배치했다.
- 레벨업: 큰 아이콘, 신규/강화/진화 배지, 레벨 변화, 이름과 효과 설명을 분리한 카드 세 장. 선택 중 중복 입력을 막고 기존 진화/연속 레벨업 대기열과 정지 소유권을 유지한다.
- 모바일 조이스틱은 실제 장비 패널 위에서 시작하지 않는다. 표시 위치 보정과 입력 기준점을 분리하여 드래그 방향이 바뀌지 않게 한다.

## 검증

기능 검사 결과: 아래 통합 검사와 기존 회귀 검사 모두 실패 0건. 로비/전투/레벨업과 일본어 소형 화면을 실제 렌더로 확인했다.

- `tools/verify_tactical_ui.gd`: 720×1280, 360×640, 가로 화면; 한국어/영어/일본어; 이어하기 유무; 기존 팝업 보존; 7무기/6패시브; 가장 긴 카탈로그 설명; 중복 선택; 진화 이후 대기 중인 레벨업과 전투 복귀.
- 기존 `verify_hud_layout`, `verify_hud_alert`, `verify_ui_icons`, `check_font_coverage`, `verify_timed_notices`, `verify_mouse_move` 검사 사용.
- `tools/shot_tactical_ui.gd -- after ko states`: 실제 렌더로 로비/HUD/레벨업/저체력+보스/진화 캡처. `-- after ja small`은 360×640 일본어 캡처.
- 캡처는 실제 Godot 4.3 렌더이며 재화·장비·레벨은 검사 스크립트가 설정한 상태다. 생성 이미지나 가공된 게임 배경을 사용하지 않는다.
- 실행 시 APPDATA를 `output/tactical_ui/userdata` 같은 격리 폴더로 지정해 사용자의 세이브에 영향을 주지 않게 한다.
- 이 환경에서는 인증서 저장소 오류와 종료 시 RID/리소스 정리 경고가 출력된다. 반환 코드와 기능 검사 결과를 별도로 확인했다. 종료 시 RID 경고는 변경 전 캡처에서도 확인됐다.

결과 이미지: `output/tactical_ui/`. 사용자 푸시 승인 후 `codex/tactical-metal-ui` 브랜치로 공유한다.


## 2026-09-14 금속 외장 수정
사용자 참조 이미지와 같은 기존 강철·황동 나인패치 프레임을 로비, HUD, 레벨업과 기본 패널에 적용. 버튼은 베벨·리벳 플레이트, 보조 메뉴는 아이콘 계열색으로 구분한다. 얇은 게이지는 평면 트랙을 유지한다. 레이아웃과 저장 인터페이스는 유지한다.
